# Scenario Catalog

This directory holds executable scenario harnesses and their evidence as the project matures. The authoritative scenario definitions live in [`docs/SCENARIOS.md`](../docs/SCENARIOS.md).

- **MVP scenarios:** Unhealthy Application and Traffic Spike.
- **Deferred to V2:** High CPU, Memory Pressure, High Error Rate.

MVP includes only the first two scenarios to keep the initial scope lean. Every scenario must be bounded, deterministic, resettable, and must produce measured evidence without invented evaluation numbers.

No scenario code exists in Phase 0.
